Baixe **NovaForge-Livre-3.0.0.apk** para criar seus próprios aplicativos.

Também incluídos três APKs independentes, cada um com nome, capa e ícone:

- **Dia-Certo.apk**: tarefas, prioridades e conclusão.
- **Estoque-Livre.apk**: produtos, vendas, baixa de estoque e lucro.
- **Bolso-Claro.apk**: receitas, despesas, saldo e backup.

O criador gera e personaliza projetos localmente. A geração de APK dentro do criador exige conta GitHub, token e internet; depende da cota do GitHub Actions. Nenhuma API paga é necessária. Os apps exportados funcionam sem NovaForge, Termux, login ou internet.

Esta publicação só acontece após testes unitários, testes de interface móvel e instalação dos três apps em emulador Android com teste de salvamento e reabertura. Isso não substitui testes em seu aparelho físico.

APKs de teste assinados. Para atualizações contínuas, use uma chave própria conforme o README dos projetos exportados. Faça backup JSON antes de desinstalar. Não há geração de imagens por IA, backend, pagamentos ou notificações agendadas nesta edição.

O NovaForge Studio original continua preservado em sua branch e nas publicações anteriores.
