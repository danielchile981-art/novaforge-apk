# Privacidade — NovaForge Studio

Os projetos, versões e preferências ficam armazenados no próprio aparelho. O NovaForge Studio não envia esses dados para um servidor próprio.

Quando o usuário conecta uma conta do GitHub para gerar APKs, o aplicativo usa o token fornecido somente para criar ou atualizar o repositório do projeto e consultar a compilação no GitHub Actions. O token fica no armazenamento local do aparelho e é excluído dos backups exportados pelo aplicativo.

O usuário pode apagar projetos individualmente ou limpar os dados do aplicativo pelas configurações do Android.
