# Histórico de versões

## 2.0.0 — Edição Unificada

- unificação do projeto original NovaForge com o motor e a interface do projeto Grok;
- nova identidade NovaForge Studio, com ícone, capa, splash e tema profissional;
- criação local por descrição e doze categorias de modelos funcionais;
- prévia ao vivo, edição de código e alterações em linguagem natural;
- biblioteca de projetos com busca, duplicação e exclusão;
- histórico de atividades e versões restauráveis;
- backup completo em JSON, preservando o token do GitHub fora do arquivo;
- exportação de código em ZIP e compilação de APK via GitHub Actions;
- suporte ao botão Voltar do Android e layouts com áreas seguras.
